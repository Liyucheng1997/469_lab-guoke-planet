# 果克星球科技馆

用 Three.js 把张祥前《果克星球奇遇》（又名《安徽农民外星球一个月见闻》）里描写的外星技术和果克星人做成可以转动、可以操作的 3D 展品。书里的设定大多没有经过科学验证，这里只按书中的描写做形象化复原。每个展品的说明都摘自原书，并标了章节。

> 注：书名和书中的星球都写作「果克」。

## 展品

| 分组 | 展品 | 可以做的操作 |
|---|---|---|
| 人物 | 果克星人（男 / 女，旁边是 1.70 m 的作者作身高参照） | 右手按胸致意、笑、离地巡航、皮肤变色 |
| 人物 | 光线虚拟人 | 烟雾凝聚成人、穿墙而过、伸手摸过去 |
| 人物 | 穿墙的发光机器人 | 从土墙里渗出、照射墙壁后穿墙、缩成紫红色水珠 |
| 交通 | 光速飞碟「区图300号」 | 冷光扫描把人吸上去、剖视环形粒子流（右手定则）、光速跃迁、直角闪现 |
| 交通 | 飞碟环形舱 | 空中一划唤出立体屏、飞船启动 |
| 网络 | 全球公众运动网（星球 + 9 个同步轨道人工场发生器） | 按书中五步走一遍瞬移流程 |
| 网络 | 瞬移 | 从密封房间瞬移到街上、在耳边一劈送来企鹅瓶、离地悬浮 |
| 网络 | 人工场发射中心（10 km 粒子环流器 + 恒星能接收器） | 发射人工场、汇聚恒星能、显示网格化空间 |
| 生活 | 时空冰箱 | 快进外面的时间、档位 ±、时空转换开关（正 / 负）、开关人工场 |
| 生活 | 虚拟墙与虚拟家具 | 关掉人工场（沙发、浴缸散掉）、挥手扩大客厅 |

所有模型都由代码生成，没有外部模型或贴图文件。

## 运行

```powershell
npm install
npm run dev
```

打开终端里显示的地址（默认 http://localhost:5173）。地址后面加 `#fridge`、`#ufo` 等可以直接打开某个展品。

构建静态网页：

```powershell
npm run build
```

产物在 `dist/`，可以直接放到任意静态网站（如 GitHub Pages）。

## 代码结构

- `src/main.js`：渲染器、界面、展品切换
- `src/stage.js`：舞台（布光、台座、辉光、镜头），改编自 threejs-stage-polish
- `src/lib.js`：发光贴图、全息材质、粒子采样、果克文字等工具
- `src/exhibits/`：每个展品一个文件，导出 `meta`（文字说明）和 `build()`（3D 内容与操作）
- `src/exhibits/guoke-body.js`：果克星人身体，多个展品共用

新增展品：在 `src/exhibits/` 里写一个模块，再在 `src/exhibits/index.js` 里登记。
